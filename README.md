# Guangyu Bai — product case studies

Personal product portfolio, deployed with GitHub Pages. Static HTML/CSS/JavaScript. No analytics, forms, credentials or private application materials.

Product statements distinguish live product, published installer, local engineering implementation, prototype, hardware validation and team contributions. Project Flow: https://pmpro.com.cn.

`assets/project-flow.png` is a screenshot from the public adkinsbai/Project-flow repository, website/assets/project-flow-canvas.png. Display fonts are subsets of Noto Sans SC and Noto Serif SC, licensed under SIL Open Font License; license files are in `assets/`.

The site is implemented in `style.css`, `projects.js` and `app.js`, without external runtime dependencies. The previous opening exhibition and spatial carousel have been removed. Seven case studies explain the audience, problem, solution, engineering challenges, personal contribution, delivery boundary and next validation question. A keyboard-accessible qualitative market map links to official product sources; it does not present comparative performance, market share or ranking. The introductory AI-generated landscape moves using bounded CSS camera drift and pointer parallax, with a pause control and reduced-motion alternative. Product scenes are actual screenshots; the knowledge-base case is explicitly an implementation diagram. Native scrolling and an anchor rail keep the longer page navigable. Full screenshots open in native accessible dialogs.

`assets/typeup-preview.png` was captured from the owner's local TypeUp frontend in a separate read-only browser preview; it is an empty/default screen with no account data, and the speech engine was not connected. `assets/trace-assistant.png` is a pre-existing screenshot of the owner's TraceCalendar development version, showing the AI assistant empty state without private conversations, memories or schedule entries. Embedded PNG provenance records these boundaries.

Product frames retain translucent glass margins; screenshot pixels remain unfiltered. `assets/provenance.json` records sources, display-stage limitations and the AI background prompt. The new Qiubi image is an unauthenticated entrance, Xiaonuan is an offline frontend scene, and VibeBoard is a default workbench with no hardware deployment. No private account, schedule, conversation or job-application data is published.
